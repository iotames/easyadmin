## 2. 实施步骤

1. 实现 task 类型注册、提交、状态机、队列并发和取消。
2. 实现进度/日志节流写入、父子任务、重试注册和重启接管。
3. 实现可控时钟 Scheduler：扫描、漏跑策略、skip 记账和 task 提交。
4. 实现本地 Storage 原子写入、内容哈希、元数据和鉴权下载。
5. 明确 Application Log reader/索引方式，构建有界查询 API。
6. 建立 system.tasks/schedules/logs/audit/files/info 模块和页面。
7. 加入保留期清理、失败告警和 graceful shutdown 测试。

## 6. 风险控制与回退

- 不在 handler 中直接起无人管理 goroutine。
- scheduler 不运行长任务。
- 不宣称当前多实例安全。
- 日志中心不得查询不存在的索引数据。

每一项涉及持久化数据的步骤必须明确备份、恢复和失败状态；不得把不可逆迁移描述为可自动回滚。
