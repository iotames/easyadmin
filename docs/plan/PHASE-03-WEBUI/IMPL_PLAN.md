## 2. 实施步骤

1. 建立 index.html、ESM boot 和全局错误处理。
2. 实现 DOM 安全工具、API Client、Notify、Store、Theme、Format。
3. 实现 Router、Page Context、动态 import 和 manifest-entry 一致性检查。
4. 实现 Layout 插槽、导航、菜单、面包屑和响应式。
5. 实现基础通用组件并定义 JSDoc 契约、dispose 语义和可访问性。
6. 实现登录/初始化、Dashboard、用户、角色、配置、个人资料页面。
7. 建立 core/components/pages/architecture 浏览器测试用例。
8. 验证生产 embed 与开发磁盘模式，进行网络面板和浏览器操作验收。

- [ ] `gofmt`、`go test ./...`、`go vet ./...` 通过。

## 6. 风险控制与回退

- 页面不得碰顶栏/侧栏等全局 DOM。
- 不允许裸 fetch、alert、自造 toast、未转义 innerHTML。
- 页面入口必须具备卸载能力。
- 前端零构建策略若要改变，必须另做架构评审。

每一项涉及持久化数据的步骤必须明确备份、恢复和失败状态；不得把不可逆迁移描述为可自动回滚。
