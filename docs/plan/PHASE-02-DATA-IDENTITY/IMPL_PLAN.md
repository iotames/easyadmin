## 2. 实施步骤

1. 核实 easydb 的数据库句柄、驱动、事务、扫描、连接池和关闭能力。
2. 定义 DataSource/Repository/Tx 门面，限制底层连接类型扩散。
3. 实现 SQL 文件加载、方言选择、参数绑定和查询超时。
4. 建立 SQLite schema、migration runner、checksum 和并发初始化保护。
5. 建立 PostgreSQL/MySQL 脚本与 DSN 门控测试；未通过者标为实验性。
6. 实现 password/session/CSRF/login limiter/bootstrap。
7. 实现用户、角色、权限、会话、审计表和 Repository。
8. 将路由权限声明、当前用户和菜单权限过滤接入 HTTP 中间件。
9. 完成 API、数据字典、安全和迁移回归。
